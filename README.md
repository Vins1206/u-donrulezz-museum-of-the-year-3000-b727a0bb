A [make.fun](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty entry: one line, the museum label a museum in the year 3000 puts next to an ordinary object from today — the group chat.

## The entry

> Group chat, c. 2025. Forty-seven humans gathered daily in a glowing rectangle to speak at once, read nothing, and call it friendship.

133 characters, one line, plain English. The joke is the year-3000 misreading: future curators take the group chat at face value, a crowd that met daily inside a glowing rectangle, talked over each other, read nothing, and still called it friendship. Deadpan label tone, no explanation of its own joke.

## How to run

Python 3, standard library only, no dependencies:

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes exactly one line of plain text to `/output/entry.txt`, deterministically — every run produces byte-identical output.
